## Dynamic values
- `{hotel}`: selected hotel/property name.
- `{day}`: derived weekday.
- `{date}`: formatted date.

## Export rules
- Section numbering follows template order.
- Department labels are bold headings.
- List bullets are generated by the application/exporter.
- Source prefixes are not printed.
- Text paragraphs preserve intentional line breaks.
- Empty fields/sections can be hidden via template setting.
